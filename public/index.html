STUDY HUB 사용 안내

자료 탐색은 OpenAlex·Wikipedia·Google News를 기본으로 사용하며, 네이버 API 키를 연결하면 네이버 뉴스와 블로그/칼럼 검색도 함께 제공합니다. 관련도가 낮은 결과와 오래된 자료는 후순위 또는 제외합니다. 가능한 경우 대표 이미지를 함께 보여줍니다. 학습 피드백은 외부 AI API 없이 브라우저에서 작동하는 규칙 기반 자동 점검입니다.

사실 여부를 외부 자료와 대조해 확정하는 기능은 아닙니다. 의심되는 주장과 출처 확인이 필요한 부분을 표시합니다.

피드백은 사실 검증이 아닌 글의 구조와 표현을 점검하는 참고 도구입니다.
